# Design mock-up

Source files of the Synergy phone-shaped mock-up, kept here as a backup. The live, editable copy is a
Claude Design artifact: https://claude.ai/artifact/58wqkZyiojDH24iUX18yEQ

- One `.dc.html` file per screen (Today, Personal, School, Email, Settings, Today signed out).
- `canvas.json` is the layout index: where each screen sits on the canvas.
- Light and dark themes: the screens follow the computer's setting, with a choice in Settings.

These files use the Claude Design format (`<x-dc>` markup and a `support.js` runtime that the Design tool provides),
so open them through the Design tool, not directly in a browser.
